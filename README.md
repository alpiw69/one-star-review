## What this is

One single-line one-star review, 103 characters, of sleep, an everyday essential everyone relies on:

> One star. Slept a full eight hours and woke up more tired than when I went to bed. Would not recommend.

It is deadpan, a real complaint filed in earnest against a thing that cannot be fixed, and it turns in the last few words.
